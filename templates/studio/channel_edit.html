{{ "lock"|icon:18 }} بيانات الاعتماد على الخادم

{% if config.channel == "telegram" %}

1. أنشئ بوتاً عبر ‎@BotFather‎ وانسخ الرمز إلى ARCMS_TELEGRAM_BOT_TOKEN في ملف البيئة.

2. أضف البوت مشرفاً في قناتك بصلاحية النشر.

3. اكتب معرّف القناة هنا (‎@اسم_القناة‎ للعامة، أو ‎-100…‎ للخاصة) ثم «اختبار الاتصال».

القالب يقبل HTML المبسّط لتيليجرام (<b> <i> <a>).

{% elif config.channel == "whatsapp" %}

تستخدم المنصة WhatsApp Business Cloud API الرسمية من Meta:

1. ضع الرمز الدائم في ARCMS_WHATSAPP_TOKEN ومعرّف رقم الهاتف في ARCMS_WHATSAPP_PHONE_NUMBER_ID.

2. اعتمد قالب رسالة من فئة «Utility» أو «Marketing» بمتغيرين: {% templatetag openvariable %}1{% templatetag closevariable %} للعنوان و{% templatetag openvariable %}2{% templatetag closevariable %} للرابط، واكتب اسمه هنا.

3. لا تُرسل إلا لمن وافق صراحةً على الاستقبال (سياسة Meta).

{% elif config.channel == "push" %}

ولّد مفاتيح VAPID بالأمر manage.py arcms_keys وضعها في ARCMS_VAPID_PUBLIC_KEY وARCMS_VAPID_PRIVATE_KEY.

يظهر زر الجرس في الموقع عند تفعيل القناة، ويُرسل الإشعار للمواد المعلَّمة «إشعار فوري» وكل عاجل.

{% else %}

اضبط خادم البريد في ملف البيئة: ARCMS_SMTP_HOST وARCMS_SMTP_USER وARCMS_SMTP_PASSWORD وARCMS_FROM_EMAIL.

ساعة الإرسال وعدد المواد في «إعدادات الموقع». الاشتراك بتأكيد مزدوج، ولكل رسالة رابط إلغاء بنقرة واحدة.
