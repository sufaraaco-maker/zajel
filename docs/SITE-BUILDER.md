# بناء موقع إخباري كامل (بخصائص شبكة قدس الإخبارية)

arcms ليست قالباً ثابتاً: الموقع العام يُبنى من غرفة التحرير بالإعدادات والأقسام والقوائم وكتل الصفحة الرئيسية. القالب الجاهز `palestine` (في `arcms_setup`) يبني بنية مشابهة لشبكات الأخبار الفلسطينية مثل «شبكة قدس الإخبارية»، ثم تعدّل المؤسسة كل شيء بهويتها.

```bash
python manage.py arcms_setup --preset palestine --site-name "اسم الشبكة" --short-name "الاسم"
```

## الخصائص وما يقابلها في arcms

## خطوات البناء

1. **الهوية**: «إعدادات الموقع» ← الاسم والشعار (نسخة فاتحة وداكنة) واللون الرئيسي ولون التمييز والخطوط. اختر «ترويسة داكنة» إن كانت هوية المؤسسة داكنة.
2. **الأقسام**: أضف الأقسام بألوانها (اللون يظهر في عنوان كتلة القسم وصفحته). القسم الفرعي يُعرض رابطاً داخل صفحة أبيه.
3. **الكتّاب**: أضف كتّاب الرأي بصورهم وصفاتهم (لا يحتاجون حسابات).
4. **القوائم**: القائمة الرئيسية بالترتيب، وعلّم «فيديو» أو «مباشر» بلون مميز.
5. **الصفحة الرئيسية**: «بنّاء الصفحة الرئيسية» ← أضف الكتل ورتّبها بالسهمين. الترتيب المقترح لموقع مثل قدس:
   1. الواجهة (مادة كبيرة وقائمة)
   2. التغطية المباشرة الجارية (تظهر فقط حين توجد تغطية)
   3. أعمدة أقسام متجاورة: القدس، الضفة، غزة
   4. تقارير (مادة كبيرة وقائمة)
   5. ملف خاص
   6. مقالات الرأي
   7. شريط الفيديو
   8. قسم الأسرى
   9. ترجمات عبرية
   10. الأكثر قراءة
   11. إنفوجراف (شريط أفقي)
   12. مدونات
   13. الاشتراك في النشرة
6. **المساحات الإعلانية** إن وُجدت.
7. **التواريخ**: أسماء الأشهر (مزدوج «أيلول/سبتمبر» شائع في فلسطين والأردن ولبنان)، والأرقام، ونظام الساعة، والهجري.

كل تغيير يظهر فوراً للقراء (تُمسح الذاكرة المؤقتة للرئيسية تلقائياً عند النشر وتعديل الكتل والقوائم والإعدادات).

## قالب لغرفة أخبار عامة

```bash
python manage.py arcms_setup --preset general
```
أقسام: محليات، سياسة، عربي ودولي، اقتصاد، رياضة، ثقافة وفنون، تكنولوجيا، صحة؛ وكتل مناسبة لها.
