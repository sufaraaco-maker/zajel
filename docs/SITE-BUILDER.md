# بناء موقع إخباري كامل (بخصائص شبكة قدس الإخبارية)

arcms ليست قالباً ثابتاً: الموقع العام يُبنى من غرفة التحرير بالإعدادات والأقسام والقوائم وكتل الصفحة الرئيسية. القالب الجاهز `palestine` (في `arcms_setup`) يبني بنية مشابهة لشبكات الأخبار الفلسطينية مثل «شبكة قدس الإخبارية»، ثم تعدّل المؤسسة كل شيء بهويتها.

```bash
python manage.py arcms_setup --preset palestine --theme modern-blue --site-name "اسم الشبكة" --short-name "الاسم"
```

## ما تغيّره كل مؤسسة من اللوحة، دون مطوّر

أسرع طريق لنسخة جديدة: **«معالج الإعداد»** في غرفة التحرير (لمدير النظام): الاسم والشعار، والمظهر، وبنية الموقع (الأقسام والقوائم والصفحة الرئيسية من قالب جاهز، دون حذف أي مادة)، والمنصات وبريد التواصل وزر الترويسة، في صفحة واحدة. وتذكّر البداية مدير النظام به ما دام الموقع بلا شعار.

| ماذا | أين |
|---|---|
| الاسم والشعار (نسخة فاتحة، وداكنة تظهر في التذييل وعلى الترويسة الداكنة وفي الوضع الداكن) وارتفاع الشعار في الترويسة وصورة المشاركة | إعدادات الموقع ← الهوية |
| مظهر جاهز بضغطة: أزرق حديث، أحمر كلاسيكي، أخضر زيتوني، ليلي، عنّابي | إعدادات الموقع ← مظاهر جاهزة |
| **ألوان الهوية البصرية**: لون رئيسي وثانوي، ولون مستقل اختياري لكل منطقة (الشريط العلوي، الترويسة، شريط القائمة، شارة العاجل، التذييل، الروابط، خلفية الصفحة، الرئيسي في الوضع الداكن). لون النص فوق كل خلفية يُختار تلقائياً ليبقى مقروءاً، والنصوص الملوّنة تُغمَّق تلقائياً إن كان لون الهوية فاتحاً (أصفر مثلاً). معاينة حيّة، وتنبيهات تباين، وألوان مقترحة تُستخرج من الشعار المرفوع | إعدادات الموقع ← الألوان والهوية البصرية |
| الخطوط وزوايا البطاقات (حادة، مدوّرة قليلاً، مدوّرة) | إعدادات الموقع ← الخطوط والشكل |
| بطاقات المشاركة بهوية الموقع (صورة العنوان والشعار واللون عند مشاركة الروابط، وبطاقة العاجل إلى تيليجرام) | إعدادات الموقع ← المشاركة على المنصات |
| شكل الترويسة: كلاسيكي (شريط قائمة ملوّن) أو حديث (الشعار والقائمة في سطر، و«المزيد» لما زاد) | إعدادات الموقع ← الترويسة والتذييل |
| زر في الترويسة («أرسل خبراً»، «تبرّع»، «البث المباشر»…) | إعدادات الموقع ← الترويسة والتذييل |
| روابط التطبيقات في التذييل (App Store وGoogle Play) | إعدادات الموقع ← الترويسة والتذييل |
| المنصات: تيليجرام، واتساب، إكس، فيسبوك، إنستغرام، يوتيوب، تيك توك | إعدادات الموقع ← روابط التواصل؛ والإرسال التلقائي من «التوزيع» |
| الأقسام وألوانها، والقوائم الثلاث (العلوية، الرئيسية، التذييل) | الأقسام؛ القوائم |
| شكل صفحة كل قسم: قائمة بعمود جانبي، أو شبكة بعرض الصفحة، أو مجلة؛ مع صورة غلاف خلف العنوان | الأقسام ← القسم |
| الخطوط: سبعة خطوط عربية مستضافة (IBM Plex، نسخ، كوفي، Cairo، Tajawal، Almarai، Amiri) للعناوين والمتن | إعدادات الموقع ← الألوان والخطوط والشكل |
| شعار المؤسسة في غرفة التحرير وصفحة الدخول والنشرة البريدية وأيقونة المتصفح | إعدادات الموقع ← الهوية |
| الصفحة الرئيسية كلها: أي كتلة، بأي ترتيب وتخطيط وخلفية | بنّاء الصفحة الرئيسية |
| التاريخ (أسماء الأشهر، الهجري، الأرقام) | إعدادات الموقع ← التاريخ والأرقام |

## خطوات البناء

1. **الهوية**: «إعدادات الموقع» ← ابدأ بمظهر جاهز، ثم الاسم والشعار (نسخة فاتحة وداكنة) واللون الرئيسي ولون التمييز والخطوط وشكل الترويسة. اختر «ترويسة داكنة» إن كانت هوية المؤسسة داكنة.
2. **الأقسام**: أضف الأقسام بألوانها (اللون يظهر في عنوان كتلة القسم وصفحته). القسم الفرعي يُعرض رابطاً داخل صفحة أبيه.
3. **الكتّاب**: أضف كتّاب الرأي بصورهم وصفاتهم (لا يحتاجون حسابات).
4. **القوائم**: القائمة الرئيسية بالترتيب، وعلّم «فيديو» أو «مباشر» بلون مميز.
5. **الصفحة الرئيسية**: «بنّاء الصفحة الرئيسية» ← أضف الكتل ورتّبها بالسهمين. نموذج الكتلة يُظهر حقول النوع المختار فقط. الترتيب الذي يبنيه القالب `palestine` (بترتيب واجهة شبكة قدس):
   1. الواجهة بتخطيط «قائمة مضغوطة» (خبر رئيسي وأبرز العناوين)
   2. موجز الأخبار (صوتي ونصي)
   3. التغطية المباشرة الجارية (تظهر فقط حين توجد تغطية)
   4. أخبار (شريط متحرك)
   5. أعمدة أقسام: القدس، الضفة، غزة
   6. متابعات القدس (شريط، العنوان على الصورة)
   7. تقارير (مادة كبيرة وقائمة، خلفية رمادية)
   8. مدونات (شريط ببطاقات الكتّاب)
   9. ترجمات عبرية (شريط متحرك)
   10. مختارات المحررين (خلفية رمادية)
   11. بطاقة «تابعونا على تيليجرام» برمز QR
   12. فيديو (خلفية داكنة)
   13. فيديو قصير عمودي (خلفية داكنة)
   14. بالأرقام (خلفية بلون الموقع)
   15. بودكاست
   16. منصاتنا على التواصل
   17. الأكثر قراءة (اليوم / هذا الأسبوع)
   18. إنفوجراف
   19. الاشتراك في النشرة (خلفية بلون الموقع)
6. **المساحات الإعلانية** إن وُجدت.
7. **التواريخ**: أسماء الأشهر (مزدوج «أيلول/سبتمبر» شائع في فلسطين والأردن ولبنان)، والأرقام، ونظام الساعة، والهجري.

كل تغيير يظهر فوراً للقراء (تُمسح الذاكرة المؤقتة للرئيسية تلقائياً عند النشر وتعديل الكتل والقوائم والإعدادات).

## قالب لغرفة أخبار عامة

```bash
python manage.py arcms_setup --preset general
```
أقسام: محليات، سياسة، عربي ودولي، اقتصاد، رياضة، ثقافة وفنون، تكنولوجيا، صحة؛ وكتل مناسبة لها.
